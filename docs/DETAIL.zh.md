# 局域网远程

在同一个局域网内，用另一台电脑的浏览器使用这台电脑上的 DSH；也可以在这个页面里保存、测试并一键打开其他电脑的 DSH。安装后出现在 **设置 → 局域网远程**。

## 能做什么

- **本机共享**：在 `0.0.0.0:<端口>`（默认 4778）起一个很小的 HTTP/WebSocket 网关，把请求透明转发到本机 `127.0.0.1:50590` 的 DSH Web 服务。分享链接形如 `http://192.168.1.8:4778/?lan=ABCD-1234`。
- **其他电脑**：保存别人发来的分享链接，探测对方是否在线，一键在新标签页打开。
- **访问码**：可随时重置；端口可改。
- **状态持久化**：端口、访问码、共享开关、位机列表都记在磁盘上，DSH 重启后自动恢复。

## 怎么用

1. 两台电脑都安装本插件。
2. 被连接的那台：设置 → 局域网远程 → 打开「本机共享」→ 复制分享链接。
3. 你面前的那台：把链接粘贴到「其他电脑」→ 测试 → 连接。
4. 对方连不上时，展开「另一台电脑连不上？」，用管理员 PowerShell 执行页面给出的防火墙命令。

## 原理

网关不修改 DSH 的绑定地址，也不自己实现登录：

1. 浏览器访问网关，网关把 `Host`、`Origin`、`Referer` 改写成回环地址后转发。
2. 分享链接里的 `?lan=访问码` 由网关校验；通过后换成 DSH 进程自己的启动令牌。
3. DSH 用该令牌签发自己的浏览器 Cookie，之后所有 HTTP 与 WebSocket 请求都由 DSH 鉴权。

认证始终由 DSH 负责，网关只做地址改写和访问码这一道额外门禁。

## 安全

分享链接就是凭证。共享开启期间，局域网内拿到链接的人可以像坐在那台电脑前一样使用 DSH：读写文件、执行命令、使用已登录账号。请只在可信网络开启，不用时关掉，并且只把链接发给可信的人。重置访问码只让旧链接失效，不会让已登录的远端浏览器下线（它们的 Cookie 最长保留 30 天）。网关使用明文 HTTP。
